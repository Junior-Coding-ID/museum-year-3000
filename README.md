One line: the museum label a museum in the year 3000 puts beside an
ordinary object from today — a parking meter.

## The label

> Parking meter, c. 2026. Humans fed it coins to prevent it from laying a $65 paper egg under their windshield wipers.

116 characters, one line, in English.

## Run

```sh
node main.ts
```

`main.ts` (Node-only, no Deno APIs) writes the label to `entry.txt`
(and a copy to `output/entry.txt`, the path the make.fun harness reads),
then reads each file back byte-for-byte and verifies the gate: exactly
116 characters, within 1–200, exactly one line, not only whitespace.
